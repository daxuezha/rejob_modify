# 再就业中心 整合版

面向《Victoria 3》的**简体中文**模组。围绕「再就业中心」与「集中营」两座建筑，提供一套**失业人口管理 + 人口处理**的玩法，并把全部操作集中到一个**日志面板**里。

**完全自包含** —— 只订阅本模组即可，不需要（也不应）再启用 Steam 创意工坊上的原「再就业中心 2.0」，两者内容重复会导致定义冲突。

当前版本：**2.0.0** ｜ 支持游戏版本：**1.13.\*** ｜ 语言：简体中文

## 1. 概览

模组围绕两座建筑展开：

| 建筑 | 定位 | 招募对象 | 修正作用域 |
|---|---|---|---|
| **再就业中心** | 面向失业人口的正规就业设施 | 失业的普通职业人口 | **建筑级**（只影响本建筑雇员） |
| **集中营** | 关押并处理「不可接触者」 | 不可接触者（`delicious`） | **州级**（只影响不可接触者） |

功能一览：

| 功能 | 说明 |
|---|---|
| **失业人群管理中心** | 一个日志条目，集中管理死亡率调节、产出比例调节、生效开关与全部决议按钮 |
| **死亡率调节** | 按 ±10% / ±100% / ±1000% 调节，合计最低为 0，最高不限 |
| **石油 / 橡胶产出比例** | 按 ±1 / ±10 / ±100 调节 0~100 的比例（0 = 纯橡胶，100 = 纯石油） |
| **修正常驻** | 两套修正**始终生效**，开关只决定「能否修改数值」（编辑锁） |
| **决议按钮化** | 原本在决议面板里的 3 条指令全部搬进日志做成按钮 |
| **不可接触者** | 新增 `delicious` 人口类型，配套转化与恢复机制 |
| **大迁徙法令** | 提高州的移民吸引力 |
| **文化社区权重** | 与原模组一致的整套权重脚本 |

## 2. 快速上手

1. 订阅 / 安装本模组，在启动器中**只启用本模组**。
2. 进入游戏，建造「**再就业中心**」或「**集中营**」。
3. 打开**决议**面板，点击「**设立失业人群管理中心**」，日志即会出现。
   - 没点这个决议也没关系：建成建筑后**最迟一个月**日志会自动出现。
4. 在日志面板里按需调节。

> 日志默认固定在右侧追踪栏，因为它的 `weight` 设得很高。

## 3. 核心面板：失业人群管理中心

日志条目 `je_rejob_management`。界面按钮**每行两个**（左减右加），从上到下排列如下：

```
┌──────────────────────────────────────────────────────┐
│ A · 死亡率调节                                        │
│   [-10%]   [+10%]                                    │
│   [-100%]  [+100%]                                   │
│   [-1000%] [+1000%]                                  │
│   [重置调节值]                                        │
├──────────────────────────────────────────────────────┤
│ B · 死亡率生效开关（默认关闭）                         │
│   [调节作用于：再就业中心]                            │
│   [调节作用于：集中营]                                │
├──────────────────────────────────────────────────────┤
│ C · 决议按钮                                          │
│   [66号指令]        [67号指令]                        │
│   [迁移失业人口至首都]                                │
├──────────────────────────────────────────────────────┤
│ D · 产出比例调节（0 = 纯橡胶，100 = 纯石油）           │
│   [-1]   [+1]                                        │
│   [-10]  [+10]                                       │
│   [-100] [+100]                                      │
│   [重置产出比例]                                      │
├──────────────────────────────────────────────────────┤
│ E · 产出比例编辑锁（默认关闭）                         │
│   [允许调节比例：再就业中心]                          │
│   [允许调节比例：集中营]                              │
└──────────────────────────────────────────────────────┘
```

### 状态栏显示

- **调节值**：当前死亡率调节值（带正负号），对两座建筑统一。
- **再就业中心**：生产方式基准值 + 调节值 = **合计死亡率**，以及是否**可调节**。
- **集中营**：同上。
- **石油比例**：当前比例值 / 100，以及是否**可调节**。
- 各建筑生产方式**不一致**时，显示为**范围值**（`最小值% ~ 最大值%`）。

### 置灰规则

| 情形 | 结果 |
|---|---|
| 对应建筑的生效开关关闭（**默认**） | 该建筑相关的调节按钮置灰 |
| 建筑不存在 | 对应的开关置灰 |
| 比例到达边界（0 或 100） | 对应方向的 ± 按钮置灰 |

## 4. 再就业中心

建筑 `building_rejob_unemployment_center`，建筑组 `rejob_unemployment_center`（父组：政府建筑）。

- **只有玩家能建造**，禁止私人建造。
- **只从失业人口池招募**（`hires_unemployed_only = yes`）。
- 三组生产方式：**生产项目**、**岗位构成**、**服务范围**。

### 4.1 生产项目（`pmg_rejob_uc_camp`）

| 生产方式 | 投入 | 产出 | 解锁 |
|---|---|---|---|
| 瓷器生产 | 煤 200 | 瓷器 500 | 默认 |
| 肉类加工 | 弹药 100、轻武器 100 | 肉类 4000 | — |
| 石油加工 | 工具 25、电力 150、发动机 25 | **石油 2000 + 橡胶 2000** | — |
| 化肥生产 | 电力 50、煤炭 150 | 化肥 1000 | 氮固定 |
| 停止配套生产 | — | 缩减运输与奢侈品产出 | — |

> **石油加工同时产出石油与橡胶**，两者的比例由 [§7](#7-石油--橡胶产出比例) 的日志面板调节。
> 默认比例 = 100，即**纯石油**产出，与原始设计一致。

### 4.2 岗位构成（`pmg_rejob_uc_pop`）

| 生产方式 | 岗位（每级） | 建筑死亡率 | 解锁 |
|---|---|---|---|
| 基础再就业岗位 | 劳工 +100,000 | +100% | 默认 |
| 铁丝网生产计划 | 劳工 +200,000 | +200% | 野战工事 |
| 电子围栏生产计划 | 劳工 +400,000 | +400% | — |
| 专业阶层岗位 | 地主 / 资本家 各 +50,000 | **+4000%** | — |

> 死亡率为**建筑级**（`building_<职业>_mortality_mult`），**只影响本建筑内该职业的雇员**，
> 不会波及同州其他建筑的同类职业。

### 4.3 服务范围（`pmg_rejob_uc_migration`）

| 生产方式 | 效果 | 解锁 |
|---|---|---|
| 服务当地 | 运输 +20；州移民吸引力 **−99** | 默认 |
| 服务全国 | 运输 +200 | 铁路 |

## 5. 集中营

建筑 `building_gulag_logging`，建筑组 `gulag_industry`（父组：政府建筑）。

- **只有玩家能建造**，且**排除四种法律**：种族隔离、文化排斥、多元文化、臣属关系。
- 三组生产方式：**切换运转方式**、**切换关押人群**、**切换服务区域**。

### 5.1 切换运转方式（`gulag_camp`）

| 生产方式 | 投入 | 产出 | 解锁 |
|---|---|---|---|
| 集中营:瓷器生产 | 煤 200 | 瓷器 500 | 默认 |
| 集中营:肉类生产 | 弹药 100、轻武器 100 | 肉类 4000 | — |
| 集中营:炼油产业 | 工具 25、电力 150、发动机 25 | **石油 2000 + 橡胶 2000** | — |
| 集中营:化肥生产 | 电力 50、煤炭 150 | 化肥 1000 | 氮固定 |
| 停止运转 | — | 缩减运输与奢侈品产出 | — |

### 5.2 切换关押人群（`gulag_pop`）

| 生产方式 | 关押人数（每级） | 州死亡率（不可接触者） | 解锁 |
|---|---|---|---|
| 基础关押 | 不可接触者 +100,000 | +100% | 默认 |
| 集中营:铁丝网 | 不可接触者 +200,000 | +200% | 野战工事 |
| 集中营:电子围栏 | 不可接触者 +400,000 | +400% | — |
| 上层关押 | 地主 / 资本家 各 +50,000 | 建筑级 **+4000%** | — |

> 集中营的死亡率走 `state_delicious_mortality_mult`，是**州级**修正。
> 由于**只有集中营会雇佣不可接触者**，其实际效果等同于「只影响营内人群」。

### 5.3 切换服务区域（`gulag_migration`）

与再就业中心的「服务范围」同构：服务当地（运输 +20，州移民吸引力 −99）/ 服务全国（运输 +200，需铁路）。

## 6. 死亡率调节

### 6.1 单位

调节值使用修正类型的**原始单位**（`percent = yes`），引擎显示时 ×100 并补 `%`：

| 变量值 | 界面显示 |
|---|---|
| `0.1` | +10% |
| `1.0` | +100% |
| `10.0` | +1000% |

即按钮上的 **`+10%` 就是真的加 10%**。

### 6.2 合计最低为 0

本模组的硬性设计：**合计不得为负**。

```
单座建筑合计 = max( 生产方式基准值 + 调节值 , 0 )
```

举例：基准 400%，调节 −1000% → 合计 `max(400 − 1000, 0) = 0`。

### 6.3 生效开关

两个开关**默认都是关闭的**。

| 再就业中心 | 集中营 | 效果 |
|---|---|---|
| 亮 | 亮 | 调节值同时作用于两座建筑 |
| 亮 | 灭 | 只作用于再就业中心 |
| 灭 | 亮 | 只作用于集中营 |
| 灭 | 灭 | 都不作用（**默认**） |

> **开关只控制「修改动作是否生效」**，不会改变调节值本身。
> 对被关闭的建筑是撤销其动态修正，对被开启的建筑是重新施加。

### 6.4 作用域对比

| | `state_<职业>_mortality_mult` | `building_<职业>_mortality_mult`（本模组采用） |
|---|---|---|
| 挂载对象 | 州 | **建筑** |
| 作用范围 | 该州**所有**该职业人口 | **仅在该建筑就业**的该职业人口 |

再就业中心雇佣的是劳工 / 地主 / 资本家，这些职业在州里到处都是。若用州级修正，**全州**同类职业都会被改 —— 严重超范围。只有建筑级修正才等价于「只影响被这个建筑招募的那部分人」。

两座建筑的最终方案：

| 建筑 | 修正类型 | 作用范围 |
|---|---|---|
| 再就业中心 | `building_laborers / aristocrats / capitalists _mortality_mult` | 仅该建筑内被招募的这几类职业 |
| 集中营 | `state_delicious_mortality_mult` | 所在州的不可接触者（只有集中营会雇佣，故等价于营内人群） |

> **修正跟随生产方式**：切换「岗位构成」后，修正会自动同步到新职业，不会残留旧职业的条目。

### 6.5 建筑面板上的合计值

建筑面板显示的死亡率 = **生产方式自带值 + 日志调节值**。

默认生产方式组合的算式：

| 生产方式组 | 默认选中 | 贡献 |
|---|---|---|
| 生产项目 | 瓷器生产 | 无（生产项目组不提供死亡率） |
| 岗位构成 | 基础再就业岗位 | `building_laborers_mortality_mult = 1` → **100%** |
| 服务范围 | 服务当地 | 无 |
| **合计** | | **100%** |

切换到「专业阶层岗位」则为 **4000%**；切换到「电子围栏」则为 **400%**。
可见面板上的数字**完全等于各生产方式修正值的算术和**，建筑本身没有贡献。

## 7. 石油 / 橡胶产出比例

### 7.1 它能做什么

「石油加工」（再就业中心）/「集中营:炼油产业」（集中营）这两种生产方式**同时产出石油与橡胶**，各 2000。日志面板上的比例用于分配这两者：

| 比例 | 实际产出 |
|---|---|
| **100**（默认） | 纯石油 |
| 75 | 1500 石油 + 500 橡胶 |
| 50 | 1000 石油 + 1000 橡胶 |
| 25 | 500 石油 + 1500 橡胶 |
| **0** | 纯橡胶 |

比例是**连续可调**的整数（0 ~ 100），按 ±1 / ±10 / ±100 调节。

> 实际产出会随**建筑等级**与**就业率**同步缩放 —— 表中数值以「满级满员」为例。

### 7.2 两个「编辑锁」

| 开关 | 作用 |
|---|---|
| **允许调节比例：再就业中心** | 开启后，可调节作用于再就业中心的比例 |
| **允许调节比例：集中营** | 开启后，可调节作用于集中营的比例 |

> ⚠️ **重要**：这两个开关是「**编辑锁**」，**不是「生效开关」**。
> - 比例修正**永远生效** —— 即使两个开关都关闭，建筑依然按当前比例产出。
> - 开关**只决定你能否点击 ± 按钮修改数值**。
>
> 默认比例 = 100，即**纯石油**，与生产方式原始设计一致。

### 7.3 行为一览

| 场景 | 行为 |
|---|---|
| 建筑刚建成（石油生产方式） | 立即按当前比例产出（默认纯石油） |
| 开关关闭（默认） | 修正照常生效；± 按钮置灰 |
| 开启开关 | ± 按钮可用，可调 0~100 |
| 调过后再关闭开关 | **比例保持不变**，产出不变 |
| 切换到非石油生产方式 | 比例修正自动移除，不残留 |
| 建筑被拆除 | 修正随建筑销毁 |
| 比例到达 0 或 100 | 对应方向的 ± 按钮置灰 |

## 8. 决议按钮

原本位于决议面板的指令，现已全部改为日志按钮。条件不满足时自动置灰。

### 66 号指令 - 不可接触者

- **花费**：50,000 国库、10 恶名。
- **条件**：玩家国家；未采用种族隔离 / 文化排斥 / 多元文化 / 臣属关系；存在基础文化接纳度低于 4 的文化。
- **效果**：把人口规模小于 3,000 且所在州对其文化接纳度低于 4 的群体转为不可接触者并迁往首都；在首都建立一座集中营；清除首都 1% 的不可接触者。

### 67 号指令 - 冤假错案

- **花费**：5,000 国库。
- **条件**：存在所在州文化接纳度高于 3 的不可接触者。
- **效果**：这些人恢复为劳动者，并获得财富分布 10 的安置。

### 迁移失业人口至首都

- **条件**：非首都州的失业人口估算值 > 0。
- **效果**：打开迁移批次选择窗口，可选择迁移 100 万 ~ 1000 万人或全部。
- **费用**：按实际迁移量每人 1 国库单位。

> 估算值为「非首都州总人口 × 失业率」的近似值，实际合格人数可能更少（事件内还会排除不可接触者）。

### 引导决议

**设立失业人群管理中心**（`rejob_open_management_decision`）：在日志中开启本面板。
若日志已在运行，再次点击会把它**重置为全新状态**（调节值归零、开关关闭）。

## 9. 不可接触者

新增的失业型人口类型 `delicious`：

- 起始生活水平 1，工资权重 0，不领私人工资，工作年龄人口比 0.75。
- 基础政治参与度 0，但会受饥饿影响（轻度 +0.25，严重 +1）。
- 资格增长脚本与原模组一致：仅在所在州对该文化的接纳度**低于 4** 时生效。

## 10. 其他内容

### 大迁徙（法令）

- **需求**：浪漫主义科技。
- **成本**：200 权威。
- **效果**：州迁徙吸引力 +20、倍率 +1。

### 未并入州处理

州所有权变更后，若新所有者是玩家且该州未并入，自动移除军营、征兵中心、海军基地。

### 文化社区权重

与原模组一致的整套 `cultural_community_creation_weight` 脚本，并叠加「大迁徙」法令的 +1 权重。

### 迁徙上限

提高单州每周的人口迁移上限（`MIGRATION_MAX_PER_STATE_INFRASTRUCTURE`）。

## 12. 常见问题

**Q：需要同时启用原「再就业中心 2.0」吗？**
A：不需要，也不要。本模组已包含原模组全部内容，同时启用会导致定义冲突。

**Q：日志没有出现？**
A：两条途径任选其一 ——
① 打开决议面板点击「设立失业人群管理中心」；
② 建造再就业中心或集中营后等最多一个月，会自动出现。

**Q：调节按钮是灰的，点不动？**
A：检查对应建筑的**生效开关**是否已点亮。两个开关默认都是关闭的。
另外，比例到达 0 或 100 时，对应方向的按钮也会置灰（这是正常的边界行为）。

**Q：我把产出比例开关关掉了，产出会变回 50/50 吗？**
A：**不会**。这两个开关是「编辑锁」，不是「生效开关」。
比例修正**永远生效**，关闭开关只是让你无法修改数值。默认比例 100，即纯石油。

**Q：为什么建筑面板上显示的死亡率和生产方式标的值不一样？**
A：面板显示的是**合计值** = 生产方式自带值 + 日志调节值（最低 0）。
详见 [§6.5](#65-建筑面板上的合计值)。

**Q：切换生产方式后，死亡率修正会跟着变吗？**
A：会。修正跟随「岗位构成」生产方式自动同步，不会残留旧职业的条目。

**Q：拆掉建筑后修正会残留吗？**
A：不会。
再就业中心是**建筑级**修正，建筑销毁时修正随之消失；
集中营是**州级**修正，但模组内置了每月自愈逻辑，最多一个月自动清理干净。
